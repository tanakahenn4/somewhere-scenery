【Git 保存手順】

対象フォルダーをターミナルから開く

① 変更確認
git status

② 変更を保存対象にする
git add .

③ PC内のGitに保存
git commit -m "今回の変更内容"

例：
git commit -m "カテゴリ選択機能を追加"

④ GitHubにも保存
git push


■ 基本は毎回この4つ

git status
git add .
git commit -m "変更内容"
git push

※ 必ず1行ずつ実行する。
※ git commit = PC内に復元ポイントを作る
※ git push = その履歴をGitHubにも送る

**「ここまで上手くいったから、この状態を残しておきたい」**というタイミングごとに、対象フォルダーでターミナルを開いて、この4つを順番に実行すればいい。

全国猫図鑑 — 公開サイトへの更新手順

対象フォルダーをターミナルで開いて、順番に実行。

git add .
git commit -m "Update site"
git push

git push が成功したら、少し待って公開サイトを更新する。

全国猫図鑑 Nekomap（公開版）

これで index.html だけでなく、icons 内の画像など変更したファイルもまとめてGitHubへ送られる。

GitHub Pagesは公開元のブランチへpushするとサイトを更新する仕組みにでき、反映には少し時間がかかる場合がある。

つまり普段はこの3行だけ覚えておけばOK。

git add .
git commit -m "Update site"
git push

なお、さっきのようにGitHub上で直接ファイルを変更した場合だけ、ローカルとGitHubの履歴がズレて fetch first が出ることがある。その場合は通常手順とは別に対処する。
